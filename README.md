# Elmo3tarf - المعترف 🎀

متجر مكياج وتجميل فاخر — مصدر أناقتك. Luxury makeup & beauty e-commerce built with React + Vite.

## التقنيات
- **React 19 + Vite 7** — واجهة سريعة (SPA)
- **Firebase (Auth + Firestore)** — تسجيل الدخول وقاعدة البيانات
- **Cloudinary** — رفع واستضافة صور المنتجات
- **Three.js + GSAP** — لاندنج بأنيميشن ومجسم روج ثلاثي الأبعاد
- **Web Push (Cloudflare Worker)** — إشعارات الموبايل

## الشغل محليًا
```bash
npm install
npm run dev      # تشغيل على جهازك
npm run build    # إنتاج نسخة جاهزة للنشر في dist/
```

## النشر
ارفع محتويات فولدر `dist/` على أي استضافة ثابتة (Netlify / Vercel / Cloudflare Pages).
